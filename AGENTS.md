# Правила работы AI-агента

Перед изменениями прочитай `PRODUCT.md`, `FLOW.md`, `DESIGN_SYSTEM.md`, `DATA_MODEL.md`, `DECISIONS.md` и `TASKS.md`.

Работай по циклу:

1. Изучи связанные файлы. Пока ничего не меняй.
2. Объясни задачу простыми словами.
3. Предложи маленький план и способ проверки.
4. Измени только согласованный кусок.
5. Запусти `npm run check`.
6. Покажи изменённые файлы, результат проверки и ручной чек-лист.
7. Обнови документацию только там, где изменилось правило.

Ограничения:

- Одна пользовательская задача за раз.
- Не меняй архитектуру и библиотеки без отдельного объяснения.
- Не добавляй зависимости, если задача решается текущим стеком.
- Не удаляй рабочее поведение ради упрощения.
- Не помещай секреты в код, логи, скриншоты и `runtime-config.js`.
- Не ослабляй доступ к данным, чтобы «быстрее заработало».
- Не делай общий редизайн внутри задачи про одну функцию.
- Если требования противоречат друг другу, остановись и назови конфликт.
