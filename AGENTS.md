# Правила работы с проектом
- Перед правками прочитай `PRODUCT.md`, `FLOW.md`, `TASKS.md` и связанные документы.
- Делай одну пользовательскую задачу за раз; сначала покажи короткий план и способ проверки.
- Меняй только согласованный кусок; не удаляй рабочее поведение и не делай общий редизайн.
- Не меняй архитектуру и библиотеки без объяснения; не добавляй ненужные зависимости.
- Не помещай секреты и реальные данные в код; фото обрабатывай только с согласием.
- При противоречии остановись и назови его; опасные действия согласуй заранее.
- После правок запусти `npm run check`.
- Покажи изменённые файлы, результат проверки и ручной чек-лист.
- Обновляй `AGENTS.md`, `CLAUDE.md` и другие документы только если изменились их правила.
