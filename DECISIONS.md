# DECISIONS.md

## 2026-07-14 — Локальный режим по умолчанию

**Почему:** участник получает первый результат без базы, аккаунтов и ключей.

**Что меняет:** база подключается только после рабочего прототипа и проверки, что данные действительно нужны.

## 2026-07-14 — Архив вместо безвозвратного удаления

**Почему:** новичок может нажать не туда. Архив безопаснее.

## 2026-07-14 — Один акцентный цвет

**Почему:** так проще сохранить визуальную иерархию во время правок агентом.

## 2026-10-08 — Обработка фото через серверный маршрут

**Почему:** ключ сервиса редактирования изображений не должен попадать в браузер или статический сайт.

**Что меняет:** маршрут `api/try-on.js` принимает фото только с явным согласием, ограничивает размер и формат, передаёт его в OpenAI Images API и возвращает JPEG без сохранения снимка в файловое хранилище проекта. Перед публичным запуском нужны настройка серверного ключа, ограничение частоты платных запросов и окончательный текст о сроках обработки данных у провайдера.

## 2026-10-09 — Замена провайдера фото-примерки на Perfect Corp

**Почему:** пользователь выбрал Perfect Corp и проверил примерку бровей на образце в песочнице.

**Что меняет:** `api/try-on.js` использует серверный `PERFECTCORP_API_KEY`, File API и асинхронную задачу Makeup Virtual Try-On вместо OpenAI. Квиз пока не вызывает маршрут. Реальные фото не тестировались; до публичного запуска нужно проверить сроки хранения у провайдера, расходы и ограничение частоты запросов.

## 2026-10-09 — Уточнение срока хранения фото

**Почему:** Perfect Corp [указывает](https://docs.perfectcorp.com/develop/file_retention_period), что загруженные и созданные изображения удаляются через 30 дней; обещание немедленного удаления было бы неверным.

**Что меняет:** перед согласием показываем срок до 30 дней. Квиз не хранит фото после сценария, но это не означает удаления у Perfect Corp. Публичную отправку фото не включаем до решения по расходам и коммерческому использованию.

## 2026-10-09 — Подключение локальной примерки

Пользователь разрешил тест с ключом Perfect Corp и расходованием API-единиц. `npm run dev` загружает `.env`, принимает запросы `/api/try-on` и возвращает изображение без записи фото в проект. Интерфейс получает согласие, блокирует повторный запрос, показывает сравнение и только затем оффер. Это разрешение на локальный тест; публикация на Netcup остаётся отдельной задачей.
