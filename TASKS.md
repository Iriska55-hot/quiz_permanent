## Выполнено локально

- [x] Квиз сокращён до трёх вопросов: зона, заметность эффекта, оттенок для выбранной зоны. Все ответы участвуют в запросе на примерку.
- [x] Первый экран заканчивается кнопкой запуска; карточки результатов и нижний блок убраны.
- [x] После вопросов пользователь выбирает фото и видит оригинал; оффер не показывается без настоящего результата примерки.

- [x] Локальный сервер загружает ключ из `.env` и обслуживает `/api/try-on`; приватные файлы недоступны через сайт.
- [x] После результата показываются исходное фото, пример, оффер и WhatsApp.
- [x] Реальный запрос через локальный `/api/try-on` на публичном образце Perfect Corp вернул PNG (HTTP 200). Проверка бровей выполнена; губы и стрелки на реальных фото ещё не проверялись.

## Сейчас — следующий шаг

- Пользователь разрешил подключение Perfect Corp для локального теста с расходованием API-единиц. Перед каждой обработкой интерфейс получает согласие на передачу фото и показывает срок хранения до 30 дней.
- Проверить своими фото три зоны; затем подготовить размещение на Netcup. Публичный запуск требует проверки тарифа, коммерческих условий и ограничения запросов.
